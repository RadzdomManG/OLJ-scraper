# Aurelius frontend

This Next.js app is the Vercel hosted portal for the Flask watcher. See the [repository setup guide](../README.md#aurelius-web-portal-vercel) for Supabase, backend, tunnel, environment, and deployment instructions.

Run `npm install`, copy `.env.example` to `.env.local` and fill in real values, then run `npm run dev`. Verify with `npm run lint` and `npm run build`.
